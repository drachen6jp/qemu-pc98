PC-98 free font image
=====================

`pc98font.bin` is a monochrome bitmap generated by `makefont.py`.  It contains
no NEC ROM data.  The checked-in image was generated from:

- GNU Unifont Japanese 17.0.04, native 8x16 and 16x16 bitmap glyphs
- DejaVu Sans Mono, Copyright 2003 Bitstream, Inc.; DejaVu changes are in
  the public domain (legacy 8x8 ANK glyphs only)

The C0 control range uses independently drawn 3x5 mnemonic labels.  Its four
arrow symbols are taken from GNU Unifont.  No glyph bitmap was copied or
traced from an NEC font ROM.

The exact Unifont source is `fonts/unifont_jp-17.0.04.bdf.gz`, SHA-256
`527925b9f03144a97e189c8715f5269b975b0340854287e3b7ac8f27cfd3bf9b`.
